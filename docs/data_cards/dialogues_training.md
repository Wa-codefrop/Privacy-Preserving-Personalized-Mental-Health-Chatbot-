# Data Card: dialogues_training.csv

- Provenance: UNVERIFIED
- Intended use: chit-chat fluency and out-of-domain negative examples
- Composition: 13,118 rows with `text`, `emotion`, `act`, and `topic`
- Notes: this corpus is not a mental-health dataset and should never be used as clinical grounding.
- Known bias: it is in-domain for conversation style but out-of-domain for crisis support.
- Forbidden use: do not use it as a substitute for expert support or safety evidence.
